Heitronix.tech - Pacote estático (Hostinger)

1) Suba o conteúdo desta pasta para public_html no painel da Hostinger.
2) O index.html usa Tailwind via CDN e carrega o logo em /assets/logo.png.
3) Favicons: favicon_32x32.png, favicon_64x64.png e favicon.ico já inclusos.
4) Formulário: usando FormSubmit com destino contato@heitronix.tech. 
   - Se quiser outro e-mail, edite o atributo 'action' do <form> no index.html.
   - Após envio, o usuário é redirecionado para /obrigado.html.
5) .htaccess incluso para fallback de SPA (evita 404 em rotas internas).
6) Cores da marca: Cyan #00CFFF, Purple #6A00FF, Navy #0A1A2F, UI #E5E7EB.
7) Para SEO, edite <title> e <meta name="description"> no <head> do index.html.
